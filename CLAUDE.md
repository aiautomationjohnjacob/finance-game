# FinanceGame

Gamified financial literacy app targeting teens through middle-aged adults (ages 13–50+).
Covers: credit card debt, mortgages, stock options, futures, the wheel strategy, simulated trading accounts, and debt management.
Mobile-first: iOS + Android. Web version planned — all infra choices must be web-portable.
Free to play, impact-first. Donation/optional premium model. No ads.
