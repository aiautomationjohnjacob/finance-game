# Finance Game — Research & Planning

## Purpose
Research-first foundation for a mobile-first personal finance education game targeting adults and high school students. Goal: maximum societal impact, not maximum profit. Freemium/donation model.

## Directory Structure

| Folder | Contents |
|--------|----------|
| `01-knowledge-gaps/` | Where people struggle most with personal finance |
| `02-demographics/` | Who is hurting most and why |
| `03-game-genre/` | What game styles hook the target audience |
| `04-teaching-methods/` | Most effective ways to teach via games |
| `05-monetization/` | Sustainable, non-barrier revenue model |
| `06-business-strategy/` | Synthesized go-to-market plan |
| `critiques/` | Research, marketing, and development critique passes |

## Key Constraints
- Mobile-first
- Free for the vast majority of users
- No ads — donation/optional premium model
- Development cost treated as $0 (AI-assisted)
- Impact > profit
